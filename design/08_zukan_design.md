# 図鑑の設計

## 二種類ある（混ぜない）

1. **自分図鑑**（アプリの核）：自分が分かっていく。中身＝自分の傾向。要件A-3そのもの。「集める」でなく「見えてくる」。完成しない（人は変わり続ける＝A-4）。現実の自分に返るので、強く促してよい。
2. **アイテム・キャラ図鑑**（楽しさ）：話す・課金で増える。集める楽しさ。入れてよいが、コンプリート強制・射幸心はなし（00bデザイン条項）。

以下は主に「自分図鑑」の設計。

---

## 中身（本質的な項目）＝心理学から論理的に、三層で

人間を捉える枠組みは三層ある。混ぜない。項目は全部で14〜15。

**層1：性格（生まれ持った、変わりにくい土台）** ＝ビッグファイブ（最も実証されている）
1. 開放性　2. 誠実性　3. 外向性　4. 協調性　5. 神経症傾向

**層2：何が自分を動かすか（動機・価値）** ＝自己決定理論＋シュワルツ価値理論
6. 充電のしかた（一人 ⇄ 人といて）　7. 大事にしていること（価値）　8. 何で動くか（自律/有能/つながり）　9. 人との距離（狭く深く ⇄ 広く浅く）

**層3：日々の感じ方のクセ（状態・表層・変わりやすい）**
10. 没頭するとき　11. 消耗するとき　12. 決め方（理屈 ⇄ 感覚）　13. 満たされる瞬間　14. 機嫌の戻し方

各項目は両極のどこかに「今は」位置する。固定でなく変わる（A-4）。中身は無色・全テーマ共通。

### 灯る順と、並ぶ順を、分ける（重要）
「浅い順に灯したい（心理学的に実感しやすい順）」と「面白い項目を上に置きたい（図鑑として）」は、両立する。別物だから。
- **灯る順（裏side・エンジン）**：浅い順。層3（日々のクセ・実感しやすい）→ 層2（動機）→ 層1（性格・いちばん底）。対話が深まるほど、底が灯る。
- **並ぶ順（表side・見た目）**：面白い・分かりやすい順。性格（タイプ・とくせい）を上に置く。
- **接続**：性格は一番上に「枠」として最初から置くが、中身は最初「？？？」（シルエット）。日々のクセが先に灯り、対話の果てに、一番上の性格が最後に灯る。＝ポケモン図鑑番号001の枠が最初からあり、捕まえると埋まるのと同じ。「一番大事なところが最後に灯る」のは図鑑として最も盛り上がる（ツァイガルニク効果が最大化）。

## 表層（テーマ）＝属性ごとに伝え方を変える

中身は同じ。ガワだけ属性で変える（デザインに作り手の色＝OK、中身は無色のまま）。
各テーマは「構造」から遊び心を変える（タブの皮だけ変えるのでなく、見せ方の骨格ごと変える）。

男女×年齢でMECEに配置し、漏れを埋めた確定ラインナップ：

| 層 | テーマ |
|---|---|
| 子ども〜10代・男子 | 図鑑風（ガチでポケモンに寄せる：タイプ／相性＝強い・弱いタイプ／とくせい／せいかく／おぼえる技／もちもの） |
| 子ども〜10代・女子 | 交換ノート風（手書き・シール・ペンの色・「○○な時うれしい」） |
| 若年・男性 | 診断風（4軸コード・レーダー・相性タイプ・強み弱み）／SNSプロフィール風（今っぽいステータス表示） |
| 若年・女性 | 交換ノート風／占い・星座風（「あなたという星」神秘的な言葉） |
| 中年・男性 | 名刺風（肩書き：○○な人／強み／力を発揮する場面／話しかけ方。一枚で人に手渡す） |
| 中年・女性 | アルバム手帳風（「わたしのこと帖」じっくり綴る・紙の質感・ほぼ日的）／お花・庭風（「こころの庭」傾向が花として咲く・育つ・季節） |
| シニア・男性 | 履歴・来歴風（「わたしの来歴」歩んできた道・培ったものを重みある形で肯定） |
| シニア・女性 | カルテ風（「こころの健康診断」所見・傾向・落ち着いた信頼感）／お花・庭風 |

テーマ総数＝図鑑・交換ノート・診断・SNSプロフィール・占い星座・名刺・アルバム手帳・お花庭・カルテ・履歴来歴（約10）。
RPGステータス風は図鑑と近すぎるため不採用。

実装の優先順位：設計上は10持つが、まず幅広い層をカバーする代表テーマ（図鑑・診断・交換ノート・名刺あたり）を完成形まで作り込み、残りは後から横展開。

### テーマは「最初に一つ選ぶ」（タブ切り替えではない）
ユーザーは自分のテーマを一つ選ぶ。タブで全部見比べるのでなく、自分の図鑑＝自分が選んだ世界観。

## 埋め方＝三方向（ジョハリの窓を立体的に照らす）

人は自分を自分だけでは正確に見られない。三方向から照らす。
1. **自分で埋める**（自己申告）＝自分が思う自分
2. **あかりが追記**（会話から見えたこと。オーキド博士／友達／専門家の立ち位置）＝対話で見えた、気づいてない自分
3. **友達が埋める**（繋がってる人が書く）＝他者から見た自分

三つが重なると「自分も他人も気づいてなかった自分」が見えてくる（ジョハリの窓）。

### 表示：項目ごとに三欄（自分・あかり・友達）。デフォルトは隠す
各項目を開くと、自分が書いたもの／あかりが見たもの／友達が書いたもの、の三つが並ぶ。閉じている時はすっきり、開くとジョハリの窓。
「自分が思う自分」と「他者から見た自分」のズレこそが、いちばんの発見になる（ズレが項目ごとに見える）。
友達が埋めるのは「一人に閉じさせない（人と交わす）」にも繋がる。各項目に、誰が灯したか（自分/あかり/友達）の印を持たせる。

## インセンティブ＝射幸心なし。やるほど良い文脈で促す

図鑑を埋める・交換することは、それ自体がユーザーの得（自分が分かる・人と繋がる）。ガチャと違い、促す方向とユーザーの得が一致。だから罪悪感なく促してよい。
射幸心（運・当たるかも）は使わず、健全な動機で：
1. **進捗の可視化**（ツァイガルニク効果）：途中まで進むと完成させたくなる。＝ホームの「灯っていく自分」。
2. **発見の喜び**：埋めるたび自分について知らなかったことが分かる。中身が自分に返る。
3. **他者からの温かいフィードバック**：友達が書いてくれたものを見る嬉しさ。交換のインセンティブ。
4. **節目の意味づけ**：ある程度灯ると、あかりが「だいぶ分かってきました」と関係の深まりとして一緒に喜ぶ。達成でなく関係。

### 二つの指標を、両方持たせる
- **数（広さ）**：いくつ灯ったか。分かりやすい進捗。「12/24」のように。
- **深さ（質）**：どれだけ向き合ったか。適当に選んだ項目より、あかりと深く話して見えた項目のほうが重い。
歯止め：報酬は「埋めた数」だけに出さない。「向き合った深さ」にも出す。数稼ぎで向き合いが浅くなるのを防ぐ（数だけだとガチャ化する）。

## まとめ（図鑑の全体）
- 中身：心理学から論理的に（8軸、無色、全テーマ共通）
- 表層：属性テーマで伝え方を変える（色つき）
- 埋め方：自分・あかり・友達の三方向（ジョハリの窓）
- インセンティブ：射幸心なし、進捗・発見・繋がり・節目。数と深さの両方を指標に
- 固定しない：図鑑は完成しない。「今、見えていること」（A-4）
