# 体験設計

## インタラクション型の分類と役割

インタラクティブ×デジタルの中を「きっかけの性質」で分類。

| 型 | 内容 | 役割 |
|---|---|---|
| ①対話型 | 言葉のやりとりで引き出す | コア |
| ②ナラティブ型 | 物語・登場人物を通じて投影 | 状況に応じて |
| ③意思決定型 | 選択・比較で価値観を浮かび上がらせる | エッセンス |
| ④表現型 | 書く・作ることで内側を外に出す | コア |
| ⑤感覚・情動型 | 音楽・映像・美しさで感情を動かす | エッセンス |
| ⑥探索・遊戯型 | 遊ぶ・探索することで自然に発見 | 状況に応じて |

## 設計の構造

```
空気をつくる（⑤）
　↓
扉を開ける（③または①）
　↓
深まる（①＋④）
　↓
没入する（②⑥、必要に応じて）
　↓
腑に落ちる
```

## 旅の骨格

心理学的に根拠のある段階。

1. **安全をつくる**：判断しない、ただ受け取る。ペースの主導権をユーザーに。
2. **体験に戻す**：抽象ではなく、具体的な瞬間・感覚・記憶へ。
3. **資源を見つける**：すでにある強さ・喜び・乗り越えた経験。
4. **パターンが見える**：バラバラな体験が一本の糸でつながる。AIが糸を反射する。
5. **腑に落ちる**：設計できない。条件を整えるだけ。

## 「これだ」が生まれる条件

自分の中から出てきた答えが、自分の理想・価値観・使命と複数同時につながった瞬間。

## 二つのモード

- **深モード**（転機）：30〜60分。主要な人生テーマを深く掘る。
- **軽モード**（日常の不安）：5〜10分。深い物語と接続したチェックイン。
